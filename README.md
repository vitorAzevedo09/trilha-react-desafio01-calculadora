# Calculator App

This is a calculator application built with [Next.js](https://nextjs.org), as part of the DIO React track challenge.

## Getting Started

To run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Then, open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

## Project Structure

- Main page: `app/page.tsx`
- Calculator component and logic: Check `components` and `app` directories.
- Styling: CSS Modules and [next/font](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) for automatic font optimization.

## Features

- Basic arithmetic operations
- Responsive design
- Built with Next.js 14, React, and TypeScript
